# Evidence ownership

User-owned during hybrid phase:
- PRICE_TECHNICALS
- DERIVATIVES_OI

System-owned:
- MARKET_TRUST
- EVENT_SHOCK
- EXECUTION_RISK provenance/derivation

Lifecycle/output-owned downstream, not acquisition inputs:
- forecast assessment
- recommendation assessment
- horizon slots
- recommendation ledger completeness
- assessment snapshot completeness

This split prevents the acquisition layer from asking the user for internal engine/lifecycle fields.
