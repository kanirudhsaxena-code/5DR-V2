# 5DR V2.1.1 — Output Assessment Control

## Purpose
Prevent omission of the two decision assessments that distinguish forecast conviction from tradeability.

## Mandatory assessments

### Forecast Assessment
Must state:
1. directional conviction level;
2. evidence supporting the forecast;
3. material change versus predecessor, if any;
4. principal risk/invalidation.

### Recommendation Assessment
Must state:
1. why the recommendation is permitted or rejected;
2. DES5;
3. Market Trust;
4. Execution Edge;
5. R:R;
6. Event Shock / kill-switch status;
7. material trade-specific risk.

## Output
The standard report remains exactly two tables. Both assessments are mandatory fields inside TABLE 1 — 5DR OUTCOME.

## Historical integrity
Existing forecasts are immutable and are not retroactively populated with assessments.

## Version
Output contract: `5DR_V2_1_1`
