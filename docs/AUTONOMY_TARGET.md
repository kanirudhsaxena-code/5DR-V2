# 5DR autonomy target

Near-term routine UX:

`upload NIFTY chart + options/OI screenshots → Run → autonomous research/acquisition → governed normalization → 5DR forecast/recommendation`

Long-term, once reliable Upstox/machine acquisition covers the two screenshot families as well, routine user input should approach zero. The acquisition architecture is therefore designed so screenshots are a temporary user-owned evidence boundary rather than a permanent requirement.
