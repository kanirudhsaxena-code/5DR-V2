# Routine user input boundary

While the Upstox pipeline does not yet fully replace visual inputs, routine user evidence is limited to:

1. NIFTY price / technical chart screenshot(s)
2. Options / OI / derivatives screenshot(s)

The user must not be asked to provide Market Trust, event/shock, execution-risk, forecast assessment, recommendation assessment, horizon slots, ledger completeness or assessment-snapshot completeness as routine inputs.

Those are system-owned acquisition/derivation/lifecycle responsibilities. Future reliable machine acquisition should reduce, not increase, routine user intervention.
