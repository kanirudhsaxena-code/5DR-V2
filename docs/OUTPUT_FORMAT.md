# Standard 5DR V2 Output

## Table 1 — 5DR Outcome
Required fields: 5-Day Forecast; Bull/Range/Bear; Expected NIFTY zone; Regime; DES5; Market Trust; Event Shock; D+1/D+3/D+5; Directional Trade; Recommendation; Contract; Entry/SL; T1/T2; R:R.

## Table 2 — 5DR Drill-down
Rows: Price + Volume + Structure; PVPO / Derivatives; Market Participation; Macro + Catalysts; Execution Edge; Market Trust; Event Shock; Evidence Delta.
Columns: Component; Score/Level; Key Outcome; Interpretation.

No additional narrative is required unless explicitly requested.
